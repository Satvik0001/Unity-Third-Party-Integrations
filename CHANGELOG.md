# Changelog

All notable changes to this package are documented here.

## [1.0.0]
### Added
- Editor window (**Tools → 3rd Party Integrations**) with Installed / Not installed panels.
- Category dropdowns, checkboxes, search and category filter.
- Four install methods: Unity registry, git URL, GitHub release (.unitypackage downloaded by the Editor), manual .unitypackage.
- Catalog: AdMob, AppLovin MAX, LevelPlay, TopOn, ATT, Firebase, AppsFlyer, Adjust, Unity Analytics, Unity IAP,
  Haptic Feedback, Feel, DOTween, Cinemachine, Facebook SDK, Native Share, UniTask, Newtonsoft Json, Addressables,
  Localization, Input System, EDM4U, Google Play Games, Mobile Notifications, Remote Config, Android Logcat.
